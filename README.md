## ✨ Features

- **Immersive UI/UX**: Dark-themed, glassmorphism-inspired design with premium micro-interactions.
- **Custom Hardware-Accelerated Cursor**: A multi-layered targeting reticle cursor that morphs colors based on the active section using `IntersectionObserver`.
- **GSAP Animations**: Complex stagger animations, magnetic buttons, and 3D tilt effects on elements.
- **Silky Smooth Scrolling**: Integrated with [Lenis](https://github.com/studio-freight/lenis) for a buttery-smooth scrolling experience across all devices.
- **Fluid WebGL Backgrounds**: Interactive, fluid simulations running on the GPU.
- **Fully Responsive**: Carefully tuned layouts for desktop, tablet, and mobile, with touch-specific ripple interactions.
- **SEO Optimized**: Complete Open Graph, Twitter cards, and semantic HTML structure.

## 🛠️ Tech Stack

### Core
- **React 19**
- **Vite**

### Animation & Physics
- **GSAP (GreenSock)** - Core animation engine
- **Lenis** - Smooth scrolling wrapper
- **WebGL** - Fluid background simulations

### Styling
- **Vanilla CSS3** (Custom Properties, Flexbox, Grid, keyframes)
- **CSS Modules / BEM structure**

## 💻 Running Locally

To run this project on your local machine:

```bash
# 1. Clone the repository
git clone https://github.com/snmcodes99/portfolio-snm.git

# 2. Navigate to the directory
cd portfolio-snm

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The site will be available at `http://localhost:5173/snm/`.

## 📦 Deployment (GitHub Pages)

This project is configured to deploy to GitHub Pages. To deploy manually:

```bash
# Builds the project to /dist and pushes to the gh-pages branch
npm run deploy
```

> Note: Ensure your `vite.config.js` has the correct `base` path (e.g., `/snm/`) corresponding to your repository name.

## 🎨 Design Philosophy

The aesthetic of this portfolio is designed to feel **tech-forward, precise, and immersive**.
- **Colors**: Deep space navy backgrounds (`#0a0e1a`) contrasted with electric cyan (`#00e7ff`) and ruby red accents.
- **Typography**: `Space Grotesk` for technical precision in headings, combined with `Inter` for highly readable body text, and `Fira Code` for code blocks.
- **Interactivity**: Moving away from static pages, elements react to the user. The cursor acts as a targeting reticle that interacts with the magnetic buttons, and the code cards tilt in 3D space relative to mouse position.
